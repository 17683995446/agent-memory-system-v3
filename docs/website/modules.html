模块汇总
模块 职责 核心组件 技术选型
核心抽象层 领域模型与接口定义 Memory, Store, Strategy, Provider Go Interface
存储后端 分层数据存储 Redis, MongoDB, S3, Milvus 官方Client
检索策略 智能检索引擎 Vector, Keyword, Hybrid 自定义实现
嵌入提供者 向量生成服务 OpenAI, BERT, Local REST API / ONNX
一致性管理 分布式共识 Raft, State Machine etcd Raft
自愈系统 故障检测与恢复 Health Check, Recovery 自定义实现
微服务框架 服务治理 gRPC, HTTP, Registry gRPC / Gin
安全模块 认证授权加密 JWT, RBAC, Encryption JWT-go / Casbin
监控告警 可观测性 Metrics, Trace, Log Prometheus / Jaeger
配置中心 配置管理 Provider, Manager, Flag ETCD / Viper
