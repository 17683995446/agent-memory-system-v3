sequenceDiagram autonumber participant F1 as Follower 1 participant F2 as Follower 2 participant F3 as Follower 3 Note over F1,F3: Leader Timeout F1->>F1: Become Candidate F1->>F1: Increment Term F1->>F1: Vote for Self F1->>F2: RequestVote RPC F1->>F3: RequestVote RPC F2->>F2: Check Term & Log F2->>F2: Grant Vote F2-->>F1: Vote Granted F3->>F3: Check Term & Log F3->>F3: Grant Vote F3-->>F1: Vote Granted F1->>F1: Receive Majority Votes F1->>F1: Become Leader F1->>F2: Heartbeat (AppendEntries) F1->>F3: Heartbeat (AppendEntries) F2-->>F1: Heartbeat ACK F3-->>F1: Heartbeat ACK Note over F1: Leader Established

故障转移时序图
sequenceDiagram autonumber participant M as Monitor participant L as Old Leader participant F1 as Follower 1 participant F2 as Follower 2 participant C as Client participant LB as Load Balancer Note over L: Leader Crashes M->>M: Health Check Timeout M->>M: Mark Leader Unhealthy F1->>F1: Election Timeout F1->>F1: Become Candidate F1->>F2: RequestVote F2-->>F1: Vote Granted F1->>F1: Become New Leader F1->>M: Report Leadership M->>M: Update Metadata M->>LB: Update Routing Table C->>LB: Write Request LB->>LB: Detect Old Leader Down LB->>LB: Route to New Leader LB->>F1: Forward Request F1->>F1: Process Request F1-->>LB: Success LB-->>C: 200 OK Note over F1: Failover Complete
